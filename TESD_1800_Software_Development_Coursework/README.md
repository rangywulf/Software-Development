# TESD 1800 - Software Development Coursework

This repository contains my coursework for ***TESD 1800: Software Development at Southwest Tech.***

## About This Repository

As I complete assignments throughout the course, this repository will be populated with a folder for each chapter. Each chapter folder contains the ```.java``` files for the assignments completed in that chapter.

## Structure
```
TESD_1800_Software_Development_Coursework/
├── README.md
├── .gitignore
├── Chapter1/
│   └── (assignment files once available)
├── Chapter2/
│   └── (assignment files once available)
└── ...
```

Each assignment is placed in the folder matching the chapter it belongs to. At the end of each chapter, the link to that chapter's folder is submitted to Canvas.
